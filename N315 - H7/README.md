This project recreates the Home and Login pages from the Jungle Cook Figma prototype. It uses Firebase Authentication for email-and-password sign-up and sign-in. Also I'm tired and going to bed :D

Features

- Responsive Home page
- Responsive Login page
- Working hamburger menu for mobile devices
- Firebase email-and-password authentication
- Navigation that updates with the signed-in user and offers sign-out
